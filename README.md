# -LAMIYA99

## 📌 Layihə Haqqında
Bu layihə modern frontend texnologiyaları ilə hazırlanmışdır. Responsiv dizayn, komponent əsaslı arxitektura və təmiz kod strukturu ilə qurulmuşdur. Layihə həm masaüstü, həm də mobil cihazlarda stabil şəkildə işləyir.

---

## 🛠 İstifadə olunan Texnologiyalar
- **React / Next.js**
- **TypeScript**
- **Tailwind CSS**
- **Axios / Fetch API**
- **Context API / Redux Toolkit**
- **Framer Motion** – animasiyalar üçün
- **Swiper.js** – slider/karusel üçün
- **Vite / Webpack**

---

## 📂 Layihə Strukturu
```bash
src/
 ├── components/        # Reusable UI komponentləri
 ├── pages/             # Səhifələr

 ├── context/           # Global state
 ├── services/          # API sorğuları
 ├── assets/            # Şəkillər & ikonlar
 ├── styles/            # Global CSS
 └── App.tsx
